# イベントと潮位の条件

`JobType` 0/1/4で使うイベントの重みと候補条件です。ステージ別の`Water`と`BanEvent`は[ステージ情報](/stage/index.html)を参照してください。

## イベントの重み {#event-weights}

イベントの初期重みは全ステージ共通です。ここでの`Difficulty`は0～1665に収めた実効難易度です。

| `Difficulty` |                                      `0` | Each other |
| -----------: | ---------------------------------------: | ---------: |
|      `0～40` |                                      `1` |        `0` |
|     `41～99` | `trunc(1 + 23 × (Difficulty - 40) / 60)` |        `0` |
|  `100～1665` |                                     `24` |        `1` |

`Difficulty`が100以上になると、8種類のイベントすべての初期重みが`1`になります。Big Runなどでは一部のイベントが候補から外れます。直前のWAVEや実行時条件による追加除外がない場合、イベント発生率は以下のとおりです。

| ステージ                    |           イベントなし |          イベントあり |
| --------------------------- | ---------------------: | --------------------: |
| Regular                     |     `75%`（`24 / 32`） |     `25%`（`8 / 32`） |
| Big Run（`Cop_Temple`以外） | 約`85.7%`（`24 / 28`） | 約`14.3%`（`4 / 28`） |
| `Cop_Temple`                | 約`88.9%`（`24 / 27`） | 約`11.1%`（`3 / 27`） |

候補に残るイベントが`n`種類の場合、イベントありの割合は`n / (24 + n)`です。

## 発生しないイベント {#excluded-events}

| `StageId`            | `EventId`       |
| -------------------- | --------------- |
| `100, 102, 104～107` | `2, 6, 7, 8`    |
| `103`                | `2, 3, 6, 7, 8` |

また、同じイベントは連続して発生しません。

## 発生しない潮位・イベントの組み合わせ {#excluded-low-tide}

| 潮位 | `IsBigRun` | `EventId`    |
| ---- | ---------: | ------------ |
| 干潮 |        `0` | `1, 2, 3, 8` |
| 干潮 |        `1` | `2, 6, 7, 8` |
| 通常 |        `0` | `6, 7`       |
| 通常 |        `1` | `2, 6, 7, 8` |
| 満潮 |        `0` | `6, 7`       |
| 満潮 |        `1` | `2, 6, 7, 8` |

イベントと潮位の計算コードは[Splatoon 3の`GameSeed`](/prng/game-seed/sp3.html#イベントと潮位の計算)を参照してください。
