# WaveSeed

`WaveSeed`とWAVEの内容の関係は、SP2とSP3で確認できた範囲が異なります。

| 作品 | 確認できたこと |
| --- | --- |
| [SP2](/prng/wave-seed/sp2.html) | `GameSeed`からWAVEごとの`WaveSeed`を作り、シャケの湧き方向とオオモノシャケの種類を決めます。 |
| [SP3](/prng/wave-seed/sp3.html) | WAVEごとに更新する共有乱数状態から、オオモノシャケの出現用`WaveSeed`を計算します。 |
