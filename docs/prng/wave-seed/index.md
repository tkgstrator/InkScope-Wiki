# WaveSeed

SP2とSP3における`WaveSeed`の扱いです。

| 作品 | 概要 |
| --- | --- |
| [SP2](/prng/wave-seed/sp2.html) | `GameSeed`からWAVEごとの`WaveSeed`を生成し、シャケの湧き方向とオオモノシャケの種類を決定 |
| [SP3](/prng/wave-seed/sp3.html) | WAVEごとに更新する共有乱数状態から、オオモノシャケ出現用の`WaveSeed`を計算 |
